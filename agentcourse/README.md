# Copilot Studio Agent 五课案例实战

入口 `/copilot-agent-course`。这是供学员跟练、讲师投屏的中文随课页，不是旧录制控制台的镜像。

## 内容与设计
- 五课：办公指南、会议行动清单、申请写入、待办查询与提醒、设备借用交接。
- 每课六步：看成果 → 拆思路 → 搭结构 → 跟着做 → 测结果 → 交作业。
- 采用手帐的“任务页 + 工作页”，暖纸色与单一珊瑚红；设计变化4/10、动效1/10、密度5/10。
- 原三段 `/copilot-demo` 保留并互链；主页首批项目加入五课入口；沿用原主页的 EN / 简 / 繁与主题行为。
- 课程为中文；视频点击后才加载 youtube-nocookie。内嵌不可用时可单独打开，也可选择本机已录制成片在页面播放；文件只生成本机Blob URL，不上传。
- 资料仅虚构数据，下载包不含真实租户、邮箱、内部地址或公司环境名称。
- 第四课只在本地筛固定回放数据，不写后台、不发邮件。日期2026-10-23，不是今天。

## 操作
投屏：点击“进入投屏”，方向键切换，Esc退出；所有键盘动作均有按钮替代。输入、下拉、按钮和弹窗聚焦时，不拦截方向键。
进度：自检仅 localStorage，不连接后台，存储失败时提示导出。导出为Markdown，打印为本课完整讲义。
路径：`?lesson=4&step=4&present=1` 可直达指定课与步骤；支持刷新及前后退。

## 材料
`public/copilot-agent-course/materials/`：每课 ZIP、五课合包、README、每课 lesson.md / Agent说明 / 虚构输入 / 搭建参考 / 未填结果的测试表。ZIP内采用ASCII文件名，内容中文。搭建参考不是可直接导入的Solution。
