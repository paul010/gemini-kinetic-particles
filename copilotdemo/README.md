# CN Print Copilot 学员演示页 Spec

## 一句话定位

`/copilot-demo` 是两小时 CN Print Copilot 线上分享的学员实践与跟练页，与 PPT 配合使用。讲师会用它完成现场案例，但页面上所有可见文字、按钮和检查项都必须从学员角色出发。

学员从会议聊天区打开本页。有对应权限时，可以下载材料、复制提示词同步跟练；暂时没有权限时，根据页面提示观察输入、输出和变化。

## 公开页面的角色规则

- 公开页面只使用学员口吻：“你收到的任务”、“你会用到”、“跟着完成”、“完成后自检”和“容易踩坑”。
- 讲师的切换时机、聊天区发送话术、备课检查、口播收束和故障备案只写在本 Spec 或 PPT 备注中，不在公开页面显示。
- 页面不称学员为“观众”，不出现“怎么讲”、“容易讲跑偏”、“上台前检查”等讲师内部用语。

## 两条同时存在的学习路径

### 有权限：同步跟练

- 下载当前 Demo 对应的学员素材。
- 复制页面中的提示词或 Agent 创建描述。
- 跟着讲师的顺序完成，并用“完成后自检”检查结果。
- 没有跟上不影响整体课程，课后可以继续。

### 暂时没有权限：观察与课后练习

- 重点观察每段的输入、输出和前后变化。
- 记住每段的一句方法总结。
- 保留页面与下载包，在获得权限后再完成。

以下表格仅供讲师与维护者使用，不需要在公开页面解释。

| PPT 位置 | 网页锚点 | 现场完成的事 | 切回 PPT 的时机 |

## 整体内容主线

三段 Demo 使用同一个 Project Lighthouse 虚构项目，只讲三次升级：

1. 任务说清。
2. 事实查准。
3. 方法复用。

页面不追求展示所有 Copilot 功能。每段只完成一个案例，让学员看懂任务、问题、输入、变化和带走的方法。

## 公开页面信息架构

1. 顶部固定导航：返回大雷主页，下载三段 Demo 完整包。
2. 开场主张：“把 Copilot 变成你的工作搭档”，并说明有权限可跟练、无权限可观察。
3. 三段快速入口：任务说清、事实查准、方法复用。
4. 三个完整的学员 Demo 区块。
5. 学员视角的 120 分钟学习路线。
6. 学员用来检查 Agent 的已知、未知、冲突、越界四类问题。
7. Excel `.Rules`、Skill Recorder、Copilot Vision 三个延伸信号。
8. 学员权限与数据安全提示。
9. 页尾完整包下载和 Microsoft 365 Copilot 入口。

## 每个 Demo 区块的学员内容契约

每段必须在同一个视觉单元内包含：

- 对应 PPT 页码和产品入口。
- 你收到的任务。
- 开始前先想一想的核心问题。
- 你会用到的输入文件或模板。
- 按实际练习顺序排列的 4 到 5 个操作步骤。
- 一键复制的学员提示词。
- 完成后自检，使用标准而不是公开黄金答案。
- 容易踩坑，帮助学员分清事实、推断、权限和边界。
- 学员可以记住的一句方法总结。
- 本段学员素材 ZIP 下载。

## 会议聊天区发送契约

这部分属于讲师备课信息，不在公开页面展示。讲师可以在分享前准备三条消息，每条包含：

- Demo 名称和对应页面锚点。
- 可以同步实践所需的权限前提。
- 本段需要下载的学员素材。
- 学员应该复制的提示词或 Agent 创建描述。
- 无权限同事应该观察的重点。

## 视觉与交互规范

- 延续大雷主页的暖色编辑风：米色纸张背景、深色正文、低饱和金色强调。
- 使用主页同款字体系统、纸张纹理、轻微光晕、大留白和细边框卡片。
- 只使用一个低饱和金色强调，不为三段 Demo 分配三种高饱和颜色。
- 主要按钮使用高对比胶囊样式，确保线上分享投屏可读。
- 页面允许纵向滚动，但每个 Demo 必须是完整视觉单元。
- 提示词复制和下载必须保持在一级页面，不隐藏到弹窗或二级页。
- 不伪造 Microsoft 界面截图。现场 Microsoft 365 Copilot 画面来自讲师的实际账号。

## 公开页面不应出现

- Go / Pilot / No-Go、Ready score、进度条或“全部通过才可演示”。
- 将分享包装成项目评审、产品上线或生产验收的语言。
- 要求 100+ 人必须同步操作的表达。
- 讲师备课检查、会议聊天区话术复制、切回 PPT 提示或“容易讲跑偏”等讲师内部内容。
- 黄金答案、讲师私有备用话术、真实内部数据或敏感租户信息。
- 把预期输出、页面截图或本地演示结果说成真实生产效果。
