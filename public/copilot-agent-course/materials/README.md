# Copilot Studio Agent 五课实战｜学员包

一课一案例、一案一模板、一课一成果。建议按 70% 提供的结构、30% 自己的业务规则完成。

顺序：01 办公指南 → 02 会议行动清单 → 03 一句话申请 → 04 待办查询与提醒 → 05 设备借用交付。

每课目录包含 Agent 说明、虚构输入、搭建参考、三组测试与 test-record.csv。
PDF / 打印：在随课网页选择“打印本课”；Markdown：每课 lesson.md。

## 课堂节奏（90 分钟参考，可按场次拆分）
5 分钟恢复与准备 → 10 分钟看成果 → 15 分钟跟演示 → 15 分钟改规则 → 20 分钟运行与对照 → 15 分钟同伴测试 → 10 分钟保存交接。
短分享可按“问题 3 分钟、视频关键段 8 分钟、实操与核对 12 分钟、练习与答疑 7 分钟”讲解，每次选一课。

## 作业提交
1. 需求卡及本次改动的业务规则。
2. Agent 说明、字段映射、实际版本与工具信息。
3. 虚构输入、人工预期、实际输出、正常与异常证据。
4. 涉及写入：对话结果 + Flow 运行 + 下游同一记录回读。
5. 涉及通知：另附实际收件核对；定时触发另验，测试后关闭。
6. 一页交接：负责人、允许范围、已测/未测、停用及恢复方法。

## 验收
业务目标15、实现25、测试25、权限20、迁移与交接15，总分100。建议75分及以上，同时必须有正常/异常证据，无虚构结果，无越权数据。无权限的学员先完成观察核对，平台实作保持未测。
三分钟展示：30秒业务问题、90秒主路径、30秒异常、30秒限制与交接。

## 使用范围
仅练习资料，不含真实公司环境名称、账号邮箱或内部地址。网页自检保存在本机，不提交后台；观看视频不代表实作通过。平台许可和入口以组织实际账号为准。材料是搭建参考，不是可直接导入的 Flow / Agent 包。
第四课固定回放日期为2026-10-23（Asia/Shanghai），不表示今天到期。正式副本需改为业务运行日并重新测试。第五课不含库存、审批与预约冲突处理。
视频需要可访问 YouTube 的网络；网络受限时使用文字、CSV 与已获准的本地视频继续讲解。
