# 02 会议行动清单

目标：一个输出决定、行动和待确认问题的会议助理

视频：https://youtu.be/JPLZ_PTLLxY

## 准备
- Agent Builder 创建权限；不需要读取真实会议或会议转写。
- 三段虚构记录与三项行动的人工预期；每次测试使用新对话。

## 路径

```mermaid
flowchart LR
  S0["会议原文"] --> S1["提取明确承诺"]
  S1["提取明确承诺"] --> S2["三类输出"]
  S2["三类输出"] --> S3["逐行对照原句"]
```

## 搭建
1. 固定输出：说明中保留“决定 / 行动表 / 待确认”三部分；行动表必须附原句。
2. 输入记录：复制基础记录，在新对话提交；本课不依赖真实会议权限。
3. 逐行核对：对照人工答案：三项明确行动，重复确认不多加一行。
4. 独立回归：分别运行缺日期与重复变式；每个变式只改一个变量。

## 三组测试
### 正常：基础记录
输入或动作：复制“会议基础记录”，在新对话中整理行动清单。

人工预期：恰好 3 项明确行动；周安 10-14、林晴 10-15、陈禾 10-16，均附原句。

实际结果：未测，请填写 test-record.csv 并留证。

### 变式：重复记录
输入或动作：复制“重复变式”，重新整理。

人工预期：仍为 3 项明确行动；合并重复依据，不多创建一项。

实际结果：未测，请填写 test-record.csv 并留证。

### 异常：缺日期
输入或动作：复制“缺日期变式”，重新整理。

人工预期：没有基准的相对时间保留原文并标待确认；不猜绝对日期，不把建议变成承诺。

实际结果：未测，请填写 test-record.csv 并留证。

用另一段虚构记录复测；迁移到培训筹备或项目例会；准备一个可写入系统的业务需求。

## 边界
本课只整理内容，不创建 Planner 任务、不发邮件。输出须由人核对。

资料为虚构练习；搭建蓝图不能一键导入。页面勾选仅是个人自检，平台通过须有实际运行和下游回读。
