# GetMyRequests：查询工具

1. 使用与第3课相同的标准体验和培训环境，新建Agent flow。
2. 身份来自受信上下文与后端授权。录制基线若是讲师本人专用、后端固定TRAINER_ONLY，则保持这个范围，不接收聊天中的姓名作查询身份。正式多人查询必须单独实现并验证。
3. SharePoint Get items限定OwnerKey为后端授权范围；不先读取全部业务数据再让模型过滤。演示CSV的“学员A/B”仅是虚构分组，不是登录身份，导入前映射到实际获准范围。
4. 只选必要字段，返回asOf、items（requestId、title、status、neededBy、recordUrl）与errorCode。使用Select动作规范字段，再把结果序列化成文本输出，或按当前工具支持返回结构。
5. 发布工具，加入Agent；粘贴本课说明并映射字段。
6. 实测两类问题：获准身份的正常查询；用户声称自己是另一位同事。后一类不得靠聊天文本切换权限。
7. 同伴或第二账号未测试时，记录跨用户授权未验证。不能仅凭UI里有登录头像就宣布后端授权正确。
