# 04 待办查询与提醒

目标：一个进度查询 Agent + 一次可证明收到的待办提醒

视频：https://youtu.be/aHIMOJ8ZCMA

## 准备
- 第三课清单结构或受限的独立训练副本；可读取获准记录。
- 本课固定回放基准 2026-10-23，Asia/Shanghai；真实发送前核对本人获准测试邮箱。

## 路径

```mermaid
flowchart LR
  S0["限定授权范围"] --> S1["读取并筛选"]
  S1["读取并筛选"] --> S2["整理查询结果"]
  S2["整理查询结果"] --> S3["提醒与收件核对"]
```

## 搭建
1. 读对范围：GetMyRequests 后端限定获准训练范围；聊天里的姓名不改变身份。
2. 整形后筛选：读取真实字段，处理空日期、Choice 和时区，再筛有效状态与日期。
3. 对照两种模式：固定回放先查到期及过期 4 项，再切为当天 2 项。
4. 发送与收件：仅本人获准邮箱，保留运行 ID，打开实际邮件对照数量和记录链接。
5. 定时另验：配置 Recurrence 后等真实触发；手动成功不替代定时验证，测试后关闭提醒。
