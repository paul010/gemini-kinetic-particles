# 05 设备借用

目标：自己的 Agent + 正常与异常测试 + 同伴试用 + 一页交接说明

视频：https://youtu.be/0di83rTyEow

## 准备
- 第三课确认与写入结构；设备、开始日期、归还日期、用途四项字段。
- 使用独立训练 Agent / Flow。数量与库存管理并非本课已实现功能。

## 路径

```mermaid
flowchart LR
  S0["设备与日期"] --> S1["规则校验"]
  S1["规则校验"] --> S2["确认后登记"]
  S2["确认后登记"] --> S3["异常测试与交接"]
```

## 搭建
1. 写需求卡：说明使用者、四项输入、校验、结果与不做的事项。
2. 迁移字段：扩展清单和工具映射；在 Flow 中校验合法日期及先后关系。
3. 保留确认：摘要后让用户确认、修改或取消；只确认才调用。
4. 跑通与复测：回读真实 ID；测日期反转、缺用途、取消、同键重试与冲突。
5. 交接给同伴：保存版本、链接、负责人、停用方式、证据和未测项；有条件时独立试用。

## 作业
保留项目日志和负责人；以实际使用问题迭代；未通过项进入待办，不扩大使用。
新增迁移作业：加入“数量”字段，要求为正整数；把字段贯穿 Topic、工具、Flow 与清单，测试数量 1 与数量 0。数量是待完成作业，不能当成视频已有功能。

## 边界
课例为制作者测试，不含库存预留、冲突预约、审批或通知。第二账号、并发、其他日期格式和故障恢复另列未测。

资料为虚构练习；搭建蓝图不能一键导入。页面勾选仅是个人自检，平台通过须有实际运行和下游回读。
