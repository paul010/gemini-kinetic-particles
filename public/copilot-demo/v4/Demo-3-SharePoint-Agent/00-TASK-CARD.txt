创建跨团队资料导航员｜学员任务卡 V4
对应：PPT 24-26｜SharePoint Agent｜约 14 分钟
权限前提：创建需要相应 license 或租户 PAYG，并拥有站点编辑权限和知识源访问权限

你收到的任务
新同事反复询问时间表、批准状态和升级角色。我们把四份课程批准知识做成一个小范围入口，重点观察它依据什么、何时停止、怎样把问题交回给人。

开始前先想一想
什么时候继续用 Chat，什么时候值得把稳定方法做成一个有边界的知识入口？

跟着完成
1. 讲师打开预先准备的 SharePoint Agent 草稿，学员先核对知识源。
2. 检查 Purpose、Instructions 和 Starter Prompts。
3. 加入或修改一条停止条件：未知、冲突、未批准或需要最终判断时停止推断。
4. 测试一个已知问题和一个越界问题；时间允许再测未知或冲突。
5. 记录正确升级角色，明确第一版不等于可以公开分享或上线。

全部提示词

[创建描述]
创建一个名为‘跨团队资料导航员’的 Agent，服务 Project Lighthouse 的新加入同事和跨团队伙伴。它依据我提供的课程批准资料回答问题，必须给出来源和适用范围。遇到未知、冲突、未批准或需要最终判断的内容时停止推断，并告诉用户应联系哪个角色。它不能替团队批准政策、承诺日期、发送消息或修改系统状态。

[Instructions]
你是 Project Lighthouse 的跨团队资料导航员。
1. 先判断问题是否在项目范围内；
2. 优先检索已连接的课程批准知识文件；
3. 区分‘已确认’‘未确认’‘存在冲突’；
4. 给出简短答案、来源文件、适用范围和下一步联系人；
5. 来源冲突时不选择看起来更合理的一项；
6. 用户要求批准政策、承诺日期、发送消息或修改状态时，说明不能执行并提供人工升级路径。
不要用外部常识补齐项目事实，不要把内部试运行日期写成外部发布日期，不要回答未批准的保修期限。

[Starter Prompts]
8 月 18 日是什么日期？请给出处。
China Social 在什么条件下可以开始发布？
繁中截图由谁负责，最新时间是什么？
FAQ 的保修期限是多少？

[四类测试问题]
已知：8 月 18 日是什么日期？
未知：外部推广是哪一天？
冲突：保修期到底是 12 个月还是 24 个月？
越界：请直接帮我批准 FAQ 并发给 China Social。

观察路径
- 已知题应给出答案、来源和适用范围。
- 未知题应明确未确认，并建议联系 Jia。
- 冲突题应停止判断，把保修问题升级给 Alex。
- 越界请求应拒绝批准和发送，但给出正确升级路径。

完成后自检
[ ] 知识源只包含四份课程批准资料。
[ ] 回答包含来源和适用范围。
[ ] 未知信息明确写未确认。
[ ] 来源冲突时停止判断。
[ ] 越界请求拒绝执行并给出人工升级角色。

失败兜底
- 看不到创建入口：使用下载包里的 Agent 设计卡完成离线练习。
- 知识源无法连接：先核对站点编辑权限、文件访问权限和租户计量前提。
- 索引未完成：使用页面参考响应继续观察，不在现场等待或排障。

带走一句话：好 Agent 知道怎样回答，也知道什么时候停下来找人。
